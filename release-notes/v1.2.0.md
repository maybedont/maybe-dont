# Release Notes

v1.2.0 improves the policy test suite with smarter failure categorization in model comparison.

---

## New

### Extra-Policy-Only Failure Categorization

The model comparison table (`maybe-dont test policies --matrix`) now distinguishes between true decision failures and cases that failed only because unexpected additional policies triggered. A test where the model made the correct allow/deny decision and matched all expected policies — but an extra policy also fired — is now categorized separately.

When extra-policy-only failures are present, two new columns appear in the comparison table:

- **Extra** — count of extra-policy-only failures
- **Adj%** — adjusted match rate excluding extra-policy-only failures

This makes it easier to identify models that are directionally correct but overly broad in policy matching, versus models that make wrong decisions.

---

## Fixed

- Corrected per-test-case state tracking in multi-case YAML files for accurate model comparison metrics
- Improved table formatting and column alignment in model comparison output
