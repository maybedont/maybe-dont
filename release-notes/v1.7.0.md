# Release Notes

This release prepares Maybe Don't Gateway for open-source distribution:
telemetry has been removed, the project is now Apache 2.0 licensed, and
documentation has been rewritten for external users and contributors.

---

## Breaking Changes

**Anonymous usage telemetry has been removed entirely.** The gateway no
longer creates `installation-id` or `metrics-state` files, no longer sends
any data to a third party, and the `MAYBEDONT_METRICS_OPTOUT` environment
variable no longer has any effect (it is now unnecessary, since there is
nothing to opt out of). Existing state files under
`~/.local/state/maybe-dont/` can be deleted safely.

Builds no longer require or accept `METRICS_DATASET` / `METRICS_API_TOKEN`
at build time; these `-ldflags` variables and Makefile/goreleaser plumbing
have been removed.

**The project is now licensed under the Apache License 2.0**, replacing the
previous proprietary license. See [LICENSE](../LICENSE) and
[NOTICE](../NOTICE).

**The Cloud Run deployment example and workflow have been removed** from
the repository (`examples/cloud_run_service.yaml`,
`.github/workflows/deploy-cloudrun.yaml`) — these described internal
infrastructure not relevant to external users.

---

## Changed

- `README.md` has been rewritten with an architecture overview, install
  instructions for Homebrew/Go/Docker/binary releases, a working quickstart
  configuration, and an explicit telemetry and fail-open/fail-closed policy.
- Added `ARCHITECTURE.md` describing the gateway as it exists today, and
  `CONTRIBUTING.md` covering build/test/release workflow (previously in
  `developer/README.md`, now folded in).
- Added `SECURITY.md` and `CODE_OF_CONDUCT.md`.
- Internal planning and design documents not relevant to external readers
  have been removed from the repository.

---
